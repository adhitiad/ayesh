# Crypto Report

Analisis mendalam proyek cryptocurrency dan blockchain.

## Fitur Analisis

| Fitur | Command | Keterangan |
|-------|---------|------------|
| Overview | `/crypto overview [token]` | Ringkasan proyek |
| Tokenomics | `/crypto tokenomics [token]` | Analisis token |
| On-Chain | `/crypto onchain [token]` | Metrik on-chain |
| Technical | `/crypto tech [token]` | Analisis teknis |
| Risk | `/crypto risk [token]` | Assessment risiko |

## Komponen Analisis

1. **Project Overview**: Tujuan, teknologi, tim
2. **Tokenomics**: Supply, distribusi, utility
3. **On-chain Metrics**: Active addresses, TVL, transaksi
4. **Competitive Analysis**: Perbandingan dengan proyek serupa
5. **Technical Analysis**: Price action, support/resistance
6. **Risk Assessment**: Regulasi, teknis, pasar

## Contoh Penggunaan

```
/crypto overview Bitcoin
/crypto tokenomics Ethereum
/crypto onchain Solana
/crypto risk Dogecoin
```

## Limitasi

- Analisis bukan saran investasi
- Pasar crypto sangat volatile
- Data on-chain mungkin tertunda
