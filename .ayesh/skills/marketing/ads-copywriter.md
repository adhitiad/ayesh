# Ads Copywriter

Buat teks iklan yang menarik dan mengkonversi untuk berbagai platform.

## Platform Iklan

| Platform | Command | Karakteristik |
|----------|---------|---------------|
| Google Ads | `/iklan google [produk]` | Headline + Description |
| Facebook | `/iklan fb [produk]` | Story-telling |
| Instagram | `/iklan ig [produk]` | Visual-first |
| LinkedIn | `/iklan linkedin [produk]` | B2B focused |
| TikTok | `/iklan tiktok [produk]` | Hook + CTA |

## Formula Copywriting

1. **AIDA**: Attention → Interest → Desire → Action
2. **PAS**: Problem → Agitate → Solution
3. **BAB**: Before → After → Bridge

## Contoh Penggunaan

```
/iklan google Software ERP untuk UKM
/iklan fb Kursus Digital Marketing Online
/iklan linkedin Layanan Konsultasi IT
```

## Limitasi

- Hasil adalah draft, perlu A/B testing
- Kebijakan iklan platform dapat berubah
