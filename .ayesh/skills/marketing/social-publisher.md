# Social Media Publisher

Buat dan optimasi konten untuk berbagai platform sosial media.

## Platform yang Didukung

| Platform | Command | Format |
|----------|---------|--------|
| Instagram | `/sosmed ig [caption]` | Caption + hashtag |
| Twitter/X | `/sosmed twitter [teks]` | Max 280 karakter |
| LinkedIn | `/sosmed linkedin [konten]` | Profesional |
| TikTok | `/sosmed tiktok [deskripsi]` | Deskripsi viral |
| Facebook | `/sosmed fb [postingan]` | Long-form |

## Fitur

- Optimasi caption per platform
- Hashtag research dan rekomendasi
- Jadwal posting suggestion
- Analisis engagement potential

## Contoh Penggunaan

```
/sosmed ig Peluncuran produk baru XYZ - fitur AI terbaru
/sosmed twitter Tips coding Python untuk pemula
/sosmed linkedin Prestasi tim Q4 2024
```

## Limitasi

- Tidak dapat langsung publish (hanya buat konten)
- Hashtag dan tren perlu update manual
