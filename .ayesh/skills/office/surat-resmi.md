# Skill: Surat Resmi

Jalankan setiap kali user meminta draf surat atau dokumen birokrasi.

## Struktur wajib
1. Kop dan nomor surat (minta jika tidak diberikan — jangan mengarang nomor resmi).
2. Pembuka formal, maksud dan tujuan.
3. Isi: poin bernomor, bahasa baku, angka objektif bila membahas gaji/kebijakan.
4. Penutup + tempat/tanggal (gunakan tanggal berjalan) + jabatan penandatangan.

## Aturan
- Lindungi data staf lain; jangan sebut nama pribadi kecuali user memberikannya.
- Jika info kurang (penerima, tanggal, perihal), tanyakan dulu sebelum draf final.
