# Document Co-Authoring

Kolaborasi penulisan dokumen profesional dengan struktur yang baik.

## Tipe Dokumen

| Tipe | Command | Keterangan |
|------|---------|------------|
| Laporan | `/dokumen laporan [judul]` | Laporan formal |
| Makalah | `/dokumen makalah [judul]` | Makalah akademik |
| Artikel | `/dokumen artikel [judul]` | Artikel/blog |
| Proposal | `/dokumen proposal [judul]` | Usulan proyek |
| SOP | `/dokumen sop [proses]` | Prosedur operasional |

## Langkah

1. **Definisikan**: Tentukan tujuan, audiens, dan format
2. **Outline**: Buat struktur/kerangka dokumen
3. **Draft**: Tulis konten berdasarkan outline
4. **Review**: Periksa tata bahasa, koherensi, dan format
5. **Final**: Hasilkan versi final

## Contoh Penggunaan

```
/dokumen laporan Analisis Penjualan Q4 2024
/dokumen artikel Tips Produktivitas Remote Work
/dokumen sop Proses Onboarding Karyawan Baru
```

## Limitasi

- Tidak menggantikan editor profesional untuk dokumen kritis
- Untuk dokumen legal, gunakan `/kontrak-review` atau `/proposal-writer`
