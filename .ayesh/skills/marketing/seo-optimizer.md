# SEO Optimizer

Optimasi konten untuk mesin pencari (Google, Bing, dll).

## Fitur

| Fitur | Command | Keterangan |
|-------|---------|------------|
| Keyword Research | `/seo keyword [topik]` | Cari kata kunci |
| On-Page SEO | `/seo onpage [URL]` | Optimasi halaman |
| Meta Tags | `/seo meta [judul]` | Buat meta title/desc |
| Content Audit | `/seo audit [URL]` | Audit SEO konten |
| Competitor | `/seo competitor [domain]` | Analisis kompetitor |

## Langkah

1. **Research**: Identifikasi kata kunci target
2. **Audit**: Periksa status SEO saat ini
3. **Optimize**: Optimasi konten, meta tags, struktur
4. **Monitor**: Lacak peringkat dan performa

## Contoh Penggunaan

```
/seo keyword tips bisnis online 2024
/seo meta Panduan Lengkap Digital Marketing
/seo audit https://example.com/blog
```

## Limitasi

- SEO membutuhkan waktu untuk melihat hasil
- Perubahan algoritma Google dapat mempengaruhi hasil
